# My agent: smart-pantry-chef
One-liner: A conversational agent that helps home cooks plan meals, discover recipes, and manage pantry inventory with a catalog of custom recipes.

Tool coverage:
- Memory: Dietary restrictions, allergies, disliked ingredients, family size, and pantry inventory
- Tools: Recipe search, recipe details lookup, pantry inventory management
- Catalog/UI: Collection of recipes rendered as rich A2UI cards and tables
- Image gen: AI-generated dish plating and presentation photos
- Sandbox: Scaling ingredient quantities and calculating total macronutrient values

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for ingredient scaling calculations, Cloud Trace for observability
